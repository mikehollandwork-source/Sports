## What this can and cannot be used for

- it is retrospective TEAM SELECTION. The rule already backs these teams when they qualify; there is no separate action in knowing which ones it has been right about
- a leader concentrated in one month is a streak the correction cannot fully price, because the permutation treats picks as independent and a team on a run is not
- implied probabilities are not de-vigged, so every SD here is conservative
